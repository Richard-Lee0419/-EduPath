# 教师注册与评委体验

## 正式教师开通

1. 管理员登录知径 EduPath，在「个人中心 → 教师邀请码与评委链接」生成一次性邀请码。填写教师邮箱可限制兑换对象。
2. 教师在登录页点击「教师邀请码」，填入邀请码、邮箱及密码，完成后进入教师工作台。是否配置注册邮件不影响账号开通。
3. 旧账号继续凭用户名或邮箱登录。已注册的邮箱可由管理员使用既有用户角色接口处理。

## 评委链接

启用一键体验时，评委打开演示站普通的 `/login` 页面，就可在主登录按钮下方选择「进入教师工作台」或「进入学生端」。首次点击会创建独立的演示班和师生账号，有效期 4 小时。在同一标签页点击「切换体验身份」，可以继续访问教师刚发布的班级课程。

评委使用一套独立演示部署。它与正式站使用相同的应用代码，可部署在同一台机器上，使用不同的域名或端口、数据库、Chroma 数据和上传存储。上线前替换演示部署的种子账号密码并为它设置单独的 JWT 密钥。评委入口默认关闭，仅在演示服务的环境变量中设置 `REVIEW_ACCESS_ENABLED=true`。

使用仓库的生产 Compose 时，可通过不同的 Compose 项目名和环境文件创建第二套服务。若使用外部数据库，评委版的数据库名、账号及相应连接配置须指向演示环境。使用 OSS 时为演示部署使用独立的 bucket 或隔离前缀与对应权限。演示部署的真实模型配置和用量由部署方决定。

将独立配置写入 `.env.review`，指定独立的 `FRONTEND_PORT` 和 `EDUPATH_IMAGE_TAG`，再从仓库根目录启动。

```bash
docker compose -p edupath-review --env-file .env.review -f docker-compose.prod.yml up -d --build
```

1. 管理员在演示站的「个人中心 → 教师邀请码与评委链接」生成评委链接，设置覆盖预计评审时间的有效期。每次生成建立一个演示班和一对专属师生账号。
2. 把新生成的链接交给对应评委。打开链接后，「评委体验」位于登录按钮下方。评委可进入教师工作台，用演示班发布一门有 PDF 的课程。
3. 点击页面上方「切换体验身份」，选择「进入学生端」，即可在学习首页打开同一演示班发布的课程，使用原有原文、带页码答疑、资源生成和测验。
4. 链接可在有效期内用于切换身份。管理员可在个人中心撤销链接。撤销和到期同时使此前签发的评委会话失效。评委凭证只在签发时显示，地址片段在页面读取后清除。

相关接口见 [API 契约](../api-contract.md#2-用户与认证)。数据库更新由 Flyway 的 V24 迁移处理。

要开放一键体验，在上述隔离环境同时设置 `REVIEW_ACCESS_ENABLED=true`、`REVIEW_ONE_CLICK_ENABLED=true`。部署会执行 V25 迁移。每日默认可创建 50 个新体验班，部署方可用 `REVIEW_ONE_CLICK_DAILY_LIMIT` 调整，普通生产站保持默认关闭。管理员签发的专属链接仍可用。

教师进入「教师工作台 → 班级课程管理」，建好或选中课程后即可「上传课程 PDF」。学生点击顶部「个人 PDF」直接上传自己的资料，前往「学习首页 → 我的班级课程」则可查看教师发布的课程。
