# 可以解释的工程取舍

本文在项目收尾时依据代码整理，用于代码评审与面试准备。它不是追溯性地证明作者当时已经考虑过所有替代方案。表述中的成本与替代方案是当前分析；历史提交能证明改动发生，不能证明全部动机。

## 1. Java 业务入口与 Python AI 服务分开

- **当前方案与证据：** 前端调用 `/api/*`，Java `AiAgentClient` 转发至 FastAPI；业务记录用 Flyway/MySQL，AI schema 和流水线独立。
- **解决的问题：** 身份、业务数据和 AI 输出有明确责任边界，Python 的模型与检索代码可单独测试。
- **可比较方案：** 单一 FastAPI 应用减少 HTTP 边界；全部 Java 可减少语言与部署栈。
- **成本与适用边界：** 三服务增加环境、接口及故障定位成本。小型团队并不必然需要这种拆分；若 AI 模块很薄，单服务更省维护。
- **历史证据：** 初始团队结构及后续接口提交保留分工；没有完整备选方案评估记录。这是可进一步梳理的设计解释。

## 2. 进程内执行器＋数据库任务快照

- **当前方案与证据：** `AgentTaskService` 保存任务快照，使用线程池与 `Future`；Python `TaskManager` 使用线程池和内存字典。
- **解决的问题：** 长模型调用不阻塞一次页面请求，用户可查状态、重连、取消和重试。
- **可比较方案：** 同步请求实现最少但等待易超时；外部消息队列与 worker 能增强调度和跨实例恢复。
- **成本与适用边界：** 当前不支持检查点续跑；重启后陈旧任务失败，重试重新执行。取消不能保证第三方模型终止。若有多实例或大量长任务，需重新考虑队列及幂等。
- **历史证据：** 任务相关提交与 API 可核对行为；“为节约维护选线程池”是当前推理，不是已确认的原始开发动机。

## 3. 结构化模型输出与确定性开发模式

- **当前方案与证据：** `app/schemas/`、`LLMGateway`、各生成 pipeline 校验 JSON、证据 ID、模式与审核；未配置模型时使用确定性规则。
- **解决的问题：** 前端渲染与数据库记录需要稳定字段；无密钥时仍能复现业务流程与失败回归。
- **可比较方案：** 自由文本加事后解析更灵活，但接口易漂移；全部测试真实模型更接近外部集成，却有成本、网络和不稳定性。
- **成本与适用边界：** schema、重试和修订需要维护且消耗 token。确定性测试不能证明真实模型质量。辅导证据摘录回退需明确标记。
- **历史证据：** [bcb5921](https://github.com/Moon-Meld/EduPath/commit/bcb5921d7e69a90de5d171c6f8894a3118a43c13) 及后续流水线支持实现；没有据此证明无幻觉或教学收益。

## 4. 审核通过才进入可检索／可发布状态

- **当前方案与证据：** 知识库 ingest 在写入向量前审核；Java `ResourceService` 校验审核结果，并限制资源读取与发布。具体回归结果见 [验证记录](validation-report.md)。
- **解决的问题：** 防止拒绝资料仍被检索、防止失败任务残留正常产物，并维护个人资源访问边界。
- **可比较方案：** 拒绝内容保存在隔离草稿以供修订，或允许批次内部分成功。
- **成本与适用边界：** Safety 拒绝会使整个生成批次失败，不保留供学生读取的拒绝正文；Safety 通过但质量不足的 draft 仍可使用已有的受控修复、比较、发布及回滚流程。自动审核不能代替完整人工教学检查。
- **历史证据：** 这是本次公开版本收尾修复，不能写成早期版本已具备；当前文档记录修复后取舍，具体日期及版本以提交/验证记录为准。

## 5. 可替换向量适配器与规则化个性化

- **当前方案与证据：** `Retriever` 选择 local 或 Chroma；`services/personalization.py` 与 Java 画像/测验/路径服务把学习信息传入生成流程。
- **解决的问题：** local 支持可重复测试，Chroma 支持持久向量数据；规则化画像与路径变化可观察、可调试。
- **可比较方案：** 直接数据库全文检索更简单；混合召回、学习排序或正式知识追踪模型需要额外实验。
- **成本与适用边界：** 本地哈希 embedding 不是语义质量基线；两种检索分数不完全同义。BM25/MMR 原型尚未接入。掌握度阈值是业务启发式，不是已验证教育测量。
- **历史证据：** 检索和路径提交支持实现；尚无固定条件下的混合检索收益或教学效果实验。
