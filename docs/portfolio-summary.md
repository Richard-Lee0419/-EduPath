# 简历与申请展示材料

使用范围：软件开发实习，以及授课型/工程型软件相关硕士的工程经历。以下写法依据当前源码、贡献说明和本地验证，不承诺招聘或招生效果。

## 项目介绍

知径 EduPath 是面向《数据结构与算法》《计算机组成原理》的学习 Web 应用。Vue 前端、Spring Boot 业务后端与 FastAPI AI 服务连接学习画像、课程证据检索、结构化资源、测验和路径调整，并保留任务状态、审核结果与生成模式。项目源自软件杯 A3 团队开发，个人公开版本明确记录贡献与验证边界。

## 简历描述

- 参与 EduPath 团队开发，主要负责 Vue 3 / TypeScript 前端、UI 设计与 AI 模块，参与 Java 后端；实现画像对话、资源展示、任务进度、路径与测验等学习流程。
- 开发/整合课程 RAG 与结构化 Agent 流水线，保存内容证据、Safety 审核及实际生成模式；将 Java 确定性评分接入画像更新和路径重规划。
- 在公开版本收尾中借助 AI 完成权限、拒绝内容、索引撤回及小测异步响应修复；通过本地真实 HTTP 和 Chromium 测试验证学习闭环、刷新持久化及拒绝上传，提供流程视频和脱敏记录。

如采用第三条，需先阅读相应修复及回归，能独立解释和维护；不能把本次 AI 辅助工作改写成原先独立完成。部署由队友主导，不写“独立完成全栈与云部署”。

证据入口：[个人贡献](../CONTRIBUTIONS.md)、[设计取舍](engineering-decisions.md)、[验证记录](validation-report.md)、[演示流程](demo-guide.md)。测试数量可以作为补充，主描述应突出验证了什么。

## 补证据后才可使用

- 可使用“已完成确定性开发模式的核心流程视频与桌面 Chromium 验证”；不要写成真实模型全流程录像、全部页面或移动端验证。
- 可使用“GitHub CI 已通过前端、Java/AI、浏览器和开发 Docker 集成验证”，并附 [运行记录](https://github.com/Richard-Lee0419/-EduPath/actions/runs/38067679122)；生产部署没有验证。
- 可使用“真实 DeepSeek 画像与 Safety 调用已核实”；本次讲义任务因 2,200-token 验证上限截断失败，不能写“真实模型全流程稳定通过”。稳定性、延迟/成本仍需要更多固定条件运行。
- “提升学习效果、服务多少学生、提高检索准确率”：需要使用数据或固定条件实验，不能从模板、规则评分和任务成功推导。
- “已上线当前版本”：本次未部署，原在线实例不能自动代表优化版本。

## 面试准备

1. 为什么分成 Vue、Java 和 Python？依据 `engineering-decisions.md` 和实际请求链解释职责、开发成本与跨服务故障。
2. Safety 和质量门禁分别控制什么？依据资源流水线、`ResourceService` 和拒绝/草稿回归解释区别。
3. 为什么测验由 Java 评分、AI 做解释？依据 `QuizService`、评估流水线和评分不变断言回答。
4. 删除文档为什么需要撤回向量？用知识库生命周期 smoke、替换/删除适配器与失败重试解释；同时说明不存在分布式事务。
5. 哪些成果是你与队友分别完成、哪些借助 AI？用贡献说明及可解释代码回答，避免只报技术栈。
