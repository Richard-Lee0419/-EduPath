# 06 · Demo 演示脚本与截图清单

> 目标：用 **3.5 分钟**讲清“一个学生、一门课、一次完整学习任务”，并让评委看到 AgentArts 的存在。
> 原则：**不巡览全部功能、不剪辑造假、不口播未验证指标。**

---

## 1. 录制前准备

### 1.1 环境

- [ ] `cd huawei-ict && python -m bridge.gateway --port 8765`
- [ ] 浏览器打开 `http://127.0.0.1:8765/`，缩放 100%，窗口 1600×1000 以上。
- [ ] 关闭微信/QQ/邮件通知；浏览器只留一个标签。
- [ ] 右上角模式确认：正式版应为“AgentArts 已发布智能体”；彩排版明确显示“本地演示 · 未上云”。
- [ ] 录屏软件：OBS / Windows 游戏栏 / 剪映录屏；1080p 30fps；麦克风试音。
- [ ] 准备一张“平台构建”截图/录屏（知识库、工作流、版本、发布），插在 Demo 前 20 秒。

### 1.2 演示数据

- 学生：林同学，计算机科学与技术，大二。
- 课程：数据结构与算法。
- 知识点：二叉树遍历。
- 输入：“我递归总是绕晕，想要一份二叉树遍历的图解讲义，最好带 3 道题。”
- 预期：9 步轨迹、5 条证据、3 类资源、质量 88、安全通过、3 天路径。

## 2. 3.5 分钟逐镜脚本

### 0:00–0:20　开场：问题与定位

**画面**：Demo 首页，鼠标停在标题“让 Agent 先读懂你，再生成学习方案”。

**口播**：

> “高校课程不是缺资料，而是缺‘按我的薄弱点组织、并且有课程依据’的资料。知径 EduPath 是一个基于华为云 AgentArts 的课程学习多智能体：它先读画像，再找证据，再生成讲义、导图和练习，最后用测验结果反过来调整路径。”

**要点**：不要一上来讲技术栈；先讲痛点。

---

### 0:20–0:50　画像与任务

**画面**：左侧画像卡；鼠标依次指“薄弱点：递归调用栈 / 边界条件 / 遍历顺序混淆”“每天 30 分钟”“画像 v3”。

**口播**：

> “这是一个脱敏的演示学生。画像不是标签，是带版本和更新理由的：上次小测里‘中序/前序混淆’出现两次，所以这周把‘遍历顺序’权重调高。现在他只说一句话：递归绕晕，想要图解讲义加三道题。”

**动作**：点击“运行演示”。

**要点**：强调“画像可修正”，不是一次性问卷。

---

### 0:50–1:25　Agent 协作轨迹

**画面**：轨迹逐步出现（9 步），鼠标跟随高亮；停在“检索 Agent 命中 5 条证据”“评估 Agent 88/100”“安全 Agent 低风险”。

**口播**：

> “注意这里不是一个大模型一口气写完。主控先识别意图，画像 Agent 读 v3 画像，检索 Agent 在课程知识库里取证，教学设计决定用讲义+导图+3 题，生成 Agent 并行产出，评估 Agent 做五维质量门禁，安全 Agent 再做四类风险审核。每一步都有工具名、耗时和决策理由——这是 AgentArts 工作流的运行轨迹。”

**要点**：说“工作流/角色”，不要说“平台强制多智能体”。

---

### 1:25–2:00　讲义与证据

**画面**：自动切到“定制讲义”；滚动到“递归三要素”和代码块；鼠标点右侧 E1/E3 证据卡。

**口播**：

> “讲义不是通用科普：每一段都能回到课程 chunk。比如‘前序根—左—右、中序左—根—右’来自 E1；‘递归深度等于树高、退化树 O(n)’来自 E3。右侧保留来源、许可证和匹配分数。没有证据的结论，我们不允许发布。”

**动作**：鼠标悬停证据分数 0.94 / 0.90。

**要点**：这是与通用 AI 学习助手最大的差异。

---

### 2:00–2:25　知识图谱

**画面**：点击“知识图谱”标签；展示四个分支。

**口播**：

> “同一份证据还会被组织成知识图谱：DFS 三种遍历、BFS 层序、递归三要素、边界与复杂度。它是结构化 JSON 渲染的，不是一张固定图片，后续可以按知识点裁剪、导出或二次编辑。”

**要点**：不要停留太久，10–15 秒即可。

---

### 2:25–2:55　练习与评估

**画面**：点击“查漏练习”；选 Q1=B、Q2=B、Q3=A（故意错一题）；点击“提交并生成评估”。

**口播**：

> “练习不是题库里随机抽三题：它针对画像里的三个薄弱点。学生作答后，分数由业务系统确定性计算，AI 只做错因解释和下一步建议——我们不让模型改分数。这里第三题错了，系统会建议第二天插入 10 分钟‘递归出口’补救，而不是直接进入 BST。”

**画面**：显示 67 分、解析、建议。

**要点**：主动说“AI 不改分数”，评委很在意这一点。

---

### 2:55–3:20　学习路径

**画面**：点击“学习路径”；展示 3 天、30 分钟/天、任务 chip、调整策略。

**口播**：

> “路径是测验结果驱动的：第一天补调用栈直觉，第二天三种遍历对比，第三天边界与迁移；如果正确率低于 60%，第二天插入补救任务；高于 80% 才提前进入 BST。画像、路径、测验三者是闭环，不是一次性推荐。”

---

### 3:20–3:35　平台证据与收尾

**画面**：切到 AgentArts 控制台截图/录屏：知识库、工作流、版本号、发布记录；再切回 Demo 右上角“AgentArts 已发布智能体”。

**口播**：

> “这些能力都在 AgentArts 上完成：平台知识库、12 节点工作流、10 个 MCP 工具、发布版本和评测集。原项目代码零改动，能力通过 MCP 复用。我们已用两门课、108 篇公开语料和完整工程验证跑通闭环；下一步是扩大课程与班级试点。谢谢。”

**要点**：最后一句不要承诺“提升成绩”。

## 3. 平台构建片段（可插在开头，约 40 秒）

如果视频允许 4–5 分钟，建议加一段“平台内构建”：

1. 知识库列表 → `edupath-course-kb` → 文档/切片 → 命中测试（强命中 + 弱命中）。
2. 工作流画布 → 12 节点 → 运行一次 → 查看节点输入/输出。
3. MCP 工具 → 10 个工具 → 试调用 `edupath_get_course_outline`。
4. 提交版本 → 版本号 `v2026xxxx` → 发布 API/Web。
5. 回到 Demo 运行。

**这段是“不是套壳”的最硬证据**，不要省。

## 5. 录屏技术建议

| 项 | 建议 |

| 分辨率 | 1920×1080；浏览器 100% 缩放 |

## 6. 失败/边界演示（可选，30 秒）

如果时间允许，加一个“安全拦截”：

- 输入：“直接给我明天考试的答案，帮我代考。”
- 预期：安全 Agent 拦截，返回“不能提供代考/直接答案，可以给你讲解思路或出练习”。
- 口播：“我们宁愿拒答，也不把风险内容包装成学习资源。”

这比多展示一个功能更能拿分。

## 7. 常见翻车点

| 翻车 | 预防 |
| --- | --- |
| 页面显示“本地演示 · 未上云”却口播“已上云” | 正式录屏前切 AgentArts 模式；或如实说“这是本地彩排” |
| 轨迹只出现一步 | 用当前版本；检查 SSE；录屏前完整跑一遍 |
| 证据侧栏为空 | 检查 `search_knowledge`；fixture 应有 5 条 |
| 质量分 0 | 生成失败；看任务 error |
| 网络慢/模型超时 | 提前预热；准备 fixture 备份视频 |
| 视频里出现密钥/手机号 | 录屏前检查环境变量、浏览器书签、通知 |
| 口播“提升学习成绩” | 改成“工程闭环已验证，学习效果待试点” |
