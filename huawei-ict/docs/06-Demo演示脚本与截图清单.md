# 06 · Demo 演示脚本与截图清单（3 分钟版）

> 目标：用 **3 分钟以内**讲清“一个学生、一门课、一次完整学习任务”，并让评委看到 **AgentArts 平台**与**原项目产品界面**。
> 原则：产品段全部使用原项目前端；平台段使用 AgentArts 控制台；不剪辑造假、不口播未验证指标。
> 依据：吉林大学报名通知明确创新赛视频“不超过 3 分钟”；官方赛题要求 Demo 展示“基于 AgentArts 构建与运行的完整流程”。

## 2. 3 分钟逐镜脚本

### 0:00–0:20　问题与定位

**画面**：原项目学习首页（`live-ui/home.png` 对应页面）。

**口播**：

> “高校课程不是缺资料，而是缺按我的薄弱点组织、并且有课程依据的资料。知径 EduPath 用华为云 AgentArts 做课程学习智能体：先读画像，再找课程证据，再生成讲义、练习和路径。”

---

### 0:20–0:50　AgentArts 构建（平台段）

**画面**：AgentArts 控制台（西南-贵阳一）。

1. 知识库 `edupath-course-kb`：文档列表、分段。
2. 命中测试：一条强命中 + 一条弱命中。
3. 3 节点工作流：开始 → 知识检索 → 大模型回答 → 结束。
4. 版本号/发布记录（各 2–3 秒）。

**口播**：

> “这是 AgentArts 里的课程知识库和工作流。知识检索节点挂课程库，回答节点只允许依据检索结果，并带引用。版本和发布记录都在平台里。”

**要点**：这一段是“不是套壳”的硬证据，不要省。

---

### 0:50–1:15　AgentArts 运行（平台段）

**画面**：工作流试运行/预览调试，输入：

> “二叉树前序、中序、后序有什么区别？”

展示：检索命中的 chunk、回答中的 `[E#]` 引用、弱证据拒答（可选）。

**口播**：

> “跑一次真实请求：检索命中课程切片，回答引用 E1/E2；如果问红黑树删除，资料没有覆盖，它会直接说‘未覆盖’，而不是编。”

---

### 1:15–1:55　产品段：画像与资源生成

**画面**：切到原项目前端。

1. 学习首页：今日任务、薄弱点“递归调用栈”、画像置信度。
2. 资源生成页：选择“递归调用栈”，生成 5 类资源；展示 9 个 Agent 完成、100%。
3. 打开一份讲义/资源详情，展示内容与“安全检查通过”。

**口播**：

> “产品端把画像、课程证据和资源生成串起来：先确认薄弱点，再生成讲义、导图、题库、代码实验和动画脚本；每个资源都带生成依据和安全检查状态。”

---

### 1:55–2:25　产品段：学习路径与评估

**画面**：

1. 学习路径：已完成/当前/补救节点，45 分钟，路径分析。
2. 学习评估：掌握度、薄弱点、下一步建议。
3. （可选）练习页：3 道题、提交。

**口播**：

> “路径不是一次性推荐：测验结果会回流画像，薄弱点会插入补救节点；评估报告给出掌握度和下一步，而不是只给一个分数。”

---

### 2:25–2:50　质量、安全与边界

**画面**：平台工作流的质量/安全节点，或产品“安全检查通过”标签；可切到一页架构图。

**口播**：

> “生成不等于发布：质量门禁和安全审核通过才输出；学术诚信、隐私、事实性都有拦截。我们目前验证两门课，不宣称提分，下一步做班级试点。”

---

### 2:50–3:00　收尾

**画面**：回到封面/架构图，显示 GitHub 分支与联系方式。

**口播**：

> “知径 EduPath，基于华为云 AgentArts 的课程学习多智能体。谢谢。”

## 5. 录屏技术规格

| 项 | 建议 |
| --- | --- |
| 分辨率 | 1920×1080 |
| 帧率 | 30fps |
| 音频 | 单独录 WAV，降噪；语速 240–260 字/分钟 |
| 字幕 | 关键句加中文字幕；术语统一 AgentArts / MCP / RAG |
| 剪辑 | 只剪等待/口误；不剪步骤、不加速关键结果 |
| 时长 | **≤3:00**；平台段 55–60 秒，产品段 75–85 秒 |
| 文件 | MP4/H.264；`知径EduPath_华为ICT2026_Demo_3min.mp4` |

## 7. 常见翻车点

| 翻车 | 预防 |
| --- | --- |
| 视频超过 3 分钟 | 先写 600 字旁白，严格按时间轴剪 |
| 平台段没有引用 | 检查知识检索节点“引用”开关 |
| 把试运行说成 API 已上线 | 口播“平台试运行/发布记录”，不说过头 |
| 产品段出现自研 Demo | 只用原项目前端；自研页不进视频 |
| 截图/视频出现密钥/手机号 | 录前检查，后期打码 |
| 全是等待画面 | 预跑一次；等待段剪掉但保留结果 |
