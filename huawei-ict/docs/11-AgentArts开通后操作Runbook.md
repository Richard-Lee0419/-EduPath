# 11 · AgentArts 公测通过后的完整操作 Runbook

> 适用：已收到 AgentArts 公测通过通知，准备做赛题 2 的最小可运行版本。
> 目标：**1.5 小时内**完成“开通体验版 → 知识库 → 3 节点工作流 → 试运行 → 提交版本/发布 → 截图”。
> 原则：先跑通 4 篇文档 + 3 个节点，不要一上来做 12 节点/10 工具。

---

## 0. 先确认：你是“通过公测”，还是“已开通服务”？

公测通过 ≠ 服务已开通，两步要分开看。

1. 打开控制台：
   <https://console.huaweicloud.com/agentarts/?region=cn-southwest-2#/home/overview>
2. 右上角区域选 **西南-贵阳一 / cn-southwest-2**。
3. 看页面状态：
   - 如果弹出“欢迎体验 AgentArts 体验版”：勾选协议 → **免费开通** → 去“资源与订阅”确认状态为 **生效中**。
   - 如果提示“仅可查看/未开通”：进 **资源与订阅** → 体验版 → **开通/免费开通**。
   - 如果已经“生效中”：直接进入第 1 步。
4. 记下：开通时间、到期时间、CU/知识库/成员额度。

> 如果公测还没通过：回公测申请页看状态/邮件；超过 5 个工作日可提交工单说明“参加华为 ICT 大赛，需尽快使用”。

## 1. 创建知识库（约 20 分钟）

**路径**：左侧导航 **开发中心 > 组件库** → **知识库** 页签 → 右上角 **创建知识库** → 选择 **默认** → 确定。

填写：

| 参数 | 值 |
| --- | --- |
| 知识库名称 | `edupath-course-kb` |
| 描述 | 高校数据结构课程证据库（二叉树遍历/基础/DFS/BST） |
| 向量模型 | `pangu_embedding` |
| 精排模型 | `pangu_rerank` |
| 解析配置 | 不配置 |
| 拆分设置 | 自动分段 |

创建后：

1. 点知识库名称进入详情。
2. 点 **上传文档**，上传 `submission/agentarts-kb-seed/` 下 4 个 `.md`：
   - `01-二叉树遍历.md`
   - `02-二叉树基础.md`
   - `03-深度优先搜索.md`
   - `04-二叉搜索树.md`
3. 等 4 个文档状态都变成 **成功**。
4. 点右上角 **命中测试**，依次输入：

| # | 问题 | 期望 |
| ---: | --- | --- |
| 1 | 二叉树前序、中序、后序有什么区别？ | 强命中 |
| 2 | 递归遍历为什么可能栈溢出？ | 强命中 |
| 3 | 二叉搜索树中序为什么有序？ | 强命中 |
| 4 | 红黑树删除的 5 种情况怎么处理？ | 弱/无命中，应拒答 |

> 命中测试是“必须做”的一步，不测等于没建。记录最高分与命中标题；第 4 条是负例，答辩要讲。

## 2. 创建 3 节点工作流（约 30 分钟）

**路径**：左侧导航 **开发中心 > 智能体管理** → **工作流** 页签 → 右上角 **创建工作流**。

1. 选择 **对话型工作流**。
2. 填写：
   - 展示名称：`知径课程问答`
   - 名称：`edupath-minimal-flow`
   - 描述：基于课程知识库的课程问答与证据引用
3. 点 **立即创建**。
4. 画布默认是 `开始 → 大模型 → 结束`；鼠标移到开始与大模型之间，点 **+**，添加 **知识检索** 节点。
5. 依次配置节点（每个节点改完点右下角 **确定**）：

### 开始节点

- 保留默认 `query` 参数，不改。

### 知识检索节点

- 输入参数：`query` 引用 **开始节点** 的 `query`。
- 知识库：添加 `edupath-course-kb`。
- 知识库设置：
  - 检索策略：**混合检索**
  - 相关度阈值：**0.35**（28+ 篇库；4 篇种子可用 0.2）
  - top_k / 召回数量：5（如果有该参数）
  - 引用/显示来源：开启（如果有）

### 大模型节点

- 模型：`DeepSeek-V3`（或控制台可选的其他预置模型，如 DeepSeek-V4-Flash）
- 温度：0.2
- 最大回复长度：2048（不够再调大）
- 输入参数：
  - `output_list` ← 知识检索节点的输出（召回片段）
  - `query` ← 开始节点的 `query`
- 系统提示词（复制）：

```text
你是「知径 EduPath」的课程答疑助教，服务高校《数据结构与算法》《计算机组成原理》课程的学生。

规则：
1. 只依据 <output_list> 中的课程证据回答，不要使用你自己的课程知识。
2. 先用一句话直接回答，再分 2-3 点给出依据；每条关键结论后标注 [E1]/[E2]，编号必须来自本次检索结果。
3. 如果检索结果与问题无关、或证据不足，直接说“现有课程资料未覆盖这个点”，不要猜、不要补。
4. 不提供代考、代写、考试直接答案；如果用户要求，改为讲解思路或出练习。
5. 不编造教材页码、论文、链接、教师姓名。
```

- 用户提示词（复制）：

```text
## 用户问题
{{query}}

## 课程知识库检索片段
{{output_list}}

请依据以上片段回答；没有依据就明确说未覆盖。
```

### 结束节点

- 输出参数引用 **大模型节点** 的输出内容，其余默认。

## 3. 试运行（约 10 分钟）

1. 点右上角 **试运行**。
2. 依次输入：
   - “二叉树前序、中序、后序有什么区别？”
   - “递归遍历为什么可能栈溢出？”
   - “红黑树删除的 5 种情况怎么处理？”
3. 检查：
   - 前两问有回答、有 `[E#]` 引用；
   - 第三问应说“未覆盖/资料没有讲到”，而不是编造；
   - 没有报错/截断。
4. 如果回答截断：调大“最大回复长度”后重新试运行。
5. 如果没引用：检查知识检索节点是否开启引用/来源，或提示词是否要求 `[E#]`。

## 4. 提交版本 + 发布（约 10 分钟）

1. 点右上角 **提交版本**。
2. 版本描述写清：
   - 知识库：`edupath-course-kb`（4 篇）
   - 检索：混合检索，阈值 0.35，top_k 5
   - 模型：DeepSeek-V3 / 实际模型名
   - 提示词：v1（只依据证据、弱证据拒答）
3. 记录版本号（截图）。
4. 点 **发布** → 选择 **API / Web**（以控制台实际选项为准）。
5. 如果发布要求 MaaS 模型授权：
   - 先不要强行发布；可以先用“试运行 + 版本记录”作为初赛证据；
   - 需要 API 时，去 MaaS 控制台（西南-贵阳一）开通模型、创建 API Key，再回填。
6. 复制 endpoint / API Key（不要发到群里/截图里）。

## 6. 额度与费用（别踩坑）

- 体验版：20 CU（一次性）+ 1GB 知识库 + 2 成员 + 50 应用 + 10 次评测。
- MaaS：首次开通送 200 万 tokens，用于调测/试运行；API 调用或额度用完需开通 MaaS，可能计费。
- 开通套餐会自动开通 **CU 按需计费**；20 CU 用完不会自动停。
- 最小 Demo **不要开**：代码解释器、浏览器工具、MCP 网关、LTS/APM/AOM；这些会额外消耗/计费。
- 去“费用中心”设置余额预警；演示前看“资源与订阅”。

## 8. 常见卡点

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 只能看、不能创建 | 未开通体验版 | 资源与订阅 → 免费开通 |
| 找不到知识库 | 区域不对 | 右上角切“西南-贵阳一” |
| 文档一直“处理中” | 解析/向量化慢 | 等 1–3 分钟；失败重传 |
| 命中测试全低分 | 分段/问题不匹配 | 换问题；检查文档标题/知识点 |
| 试运行无引用 | 引用开关/提示词 | 开启引用；提示词要求 `[E#]` |
| 大模型回答截断 | 最大回复长度太小 | 调到 2048/4096 |
| 发布要 MaaS 授权 | 未配置模型 Key | 先录试运行+版本；需要 API 再配 |
| 第 3 个成员进不来 | 体验版 2 成员 | 共用主账号 |
