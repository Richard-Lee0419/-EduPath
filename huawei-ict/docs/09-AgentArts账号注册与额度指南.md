## 1. 准备材料

- 手机号/邮箱（能收验证码与审核通知）。
- 身份证（个人实名）或营业执照/授权书（企业实名）。
- 学校/团队名称、使用场景一句话（申请公测用）：
  > 高校课程学习智能体：基于课程知识库做个性化讲义、练习与学习路径。
- 一张可用的支付方式（可选；体验版免费，但超出额度会计费）。

## 2. 注册华为云账号 + 实名认证

1. 打开 <https://www.huaweicloud.com/>，点右上角“注册”。
2. 用手机号/邮箱注册，完成验证，设置密码。
3. 登录后进入“账号中心” → “实名认证”。
4. 选择“个人认证”或“企业认证”：
   - 个人：身份证 + 人脸/银行卡验证，通常几分钟。
   - 企业：营业执照、法人信息、对公打款等，时间更长。
5. 确认账号状态为“已实名认证”，且**没有欠费**。

> 比赛演示用个人实名即可；如果学校有企业账号，按学校流程，不要用未实名的账号。

## 3. 申请 AgentArts 公测

官方文档明确：AgentArts 目前处于公测阶段，**必须先申请公测**，才能免费体验或购买。

1. 打开公测申请页：
   <https://account.huaweicloud.com/usercenter/#/betaManagement?serviceCode=beta_agentarts>
   （也可以从产品页点“申请公测”进入。）
2. 如果弹出“诚邀您参与智果（AgentArts）智能体平台公测”，点“立即申请”。
3. 填写申请信息：
   - 账号类型：个人/企业；
   - 姓名、手机、邮箱；
   - 公司/学校、职位/身份；
   - 使用场景：写“高校课程学习智能体/教育”，不要写空话；
   - 勾选《公测试用服务协议》。
4. 点“申请公测”。
5. 等待审核，官方说明**预计 5 个工作日**；结果通过邮件/短信通知。

> 建议今天就提交。若比赛截止临近，提交后联系组委会/华为云工单说明参赛，询问是否能加急；不要假设一定加急。

## 4. 开通体验版

公测通过后：

1. 打开控制台：
   <https://console.huaweicloud.com/agentarts/?region=cn-southwest-2#/home/overview>
2. 右上角区域确认是 **西南-贵阳一 / cn-southwest-2**。
3. 如果弹出“欢迎体验 AgentArts 体验版”：
   - 勾选《AgentArts 服务声明》；
   - 点“免费开通”。
4. 开通后进入“资源与订阅”：
   - 体验版状态从“订单未就绪”变为“生效中”；
   - 查看套餐信息、购买记录、用量。
5. 记下：开通时间、到期时间、当前 CU/存储/成员数。

> 体验版默认 1 个月并自动续期；体验版本身免费，但超出 20 CU 会按需计费。

## 5. 区域：只选西南-贵阳一

- AgentArts 控制台/运行时的官方入口使用 `region=cn-southwest-2`（西南-贵阳一）。
- 知识库、模型、运行时、SWR 镜像都要在**同一区域**，否则互相看不到。
- 进入控制台后，先看右上角区域；不是“西南-贵阳一”就切换。
- MaaS 模型也要在“西南-贵阳一”开通/选择；跨区域 endpoint 容易失败。

> 如果未来开放其他区域，以控制台为准；当前按官方入口走贵阳一最稳。

## 6. 额度：体验版 + MaaS 免费 tokens

### 6.1 AgentArts 体验版

| 项 | 额度 | 说明 |
| --- | ---: | --- |
| Agent 计算单元 CU | **20 CU** | 一次性赠送，不是每月重置；用完后按需计费 |
| 知识库空间 | **1 GB** | 4 篇演示文档足够 |
| 成员数 | **2 名** | 主账号 + 1 个 IAM 用户；第 3 人进不来 |
| 应用数 | **50 个** | 智能体/工作流总数 |
| 评测实验 | **10 次免费** | 超出后体验版不可继续 |
| 应用自演进 | 不支持 | 决赛前也不需要 |

### 6.2 MaaS 模型

- 首次开通赠送 **2,000,000 tokens**。
- 适用：模型调测、智能体试运行。
- **通过 API 调用智能体，或免费额度用完**：需要开通 MaaS 模型服务并设置鉴权，可能产生费用。
- 退订后重新开通不再赠送；已获赠 tokens 仍可用。

### 6.3 重要计费提醒

官方文档写明：**开通任意套餐包后，系统会自动开通 CU 按需计费**。所以：

- 20 CU 用完后不会“自动停止”，会按 CU 计费；
- 代码解释器、浏览器工具、MCP 网关、记忆、评测都会消耗 CU；
- LTS/APM/AOM 是关联服务，按各自规则收费；最小 Demo 不需要开；
- 建议在“费用中心”设置余额预警/预算，演示前检查可用额度。

## 7. 模型授权：什么时候需要 MaaS？

### 情况 A：只做平台试运行/预览调试

- 用平台赠送的 200 万 tokens 即可；
- 在智能体/工作流里选一个预置模型（如 DeepSeek-V4-Flash、GLM-5.3，以实际列表为准）；
- 不需要自己买 MaaS。

### 情况 B：发布 API / 通过接口调用

- 平台会要求 MaaS 模型授权，否则提示“MaaS 模型未配置授权”；
- 需要：
  1. 进入 MaaS 控制台，区域选“西南-贵阳一”；
  2. “模型推理 → 在线推理”选择模型；
  3. 开通模型服务/获取 endpoint；
  4. 创建 API Key（鉴权）；
  5. 回到 AgentArts 的模型配置，填 endpoint + API Key；
  6. 发布 API，用 curl 调一次，保存返回。

> 如果只是录初赛视频，试运行 + 发布记录通常够用；要展示 API 调用再配 MaaS。

## 8. 团队/IAM：只有 2 个成员名额

- 主账号默认是租户管理员，拥有全部权限。
- 如需给队友 IAM 用户：
  1. 进入 IAM（新版）：<https://console.huaweicloud.com/iam5/#/overview>
  2. 创建用户；
  3. 给用户授予 `AgentArtsFullAccessPolicy`；
  4. 如需智能体身份服务，再授 `AgentIdentityFullAccessPolicy`；
  5. 代码解释器相关自定义策略只在需要时加，最小 Demo 不需要。
- 体验版只有 2 名成员：主账号 + 1 个 IAM。3 人团队建议共用主账号操作，其他人看屏幕/录屏，不要创建第 3 个成员。

## 11. 常见坑

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 只能看、不能创建 | 未申请公测/未开通体验版 | 先公测，再免费开通 |
| 找不到知识库/模型 | 区域不对 | 右上角切“西南-贵阳一” |
| 发布提示 MaaS 未授权 | 未开通 MaaS/未配 Key | 按第 7 节配置，或先只录试运行 |
| 第 3 个成员进不来 | 体验版仅 2 成员 | 共用主账号，不建第 3 人 |
| 突然产生费用 | 20 CU 用完，自动按需 | 费用中心设预警；少开代码解释器/浏览器/MCP |
| 评测跑不了 | 10 次免费用完 | 体验版不可继续；省着用 |
| 审核太慢 | 公测 5 个工作日 | 立即申请；联系组委会/工单询问加急 |
