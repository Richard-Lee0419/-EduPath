## 二、项目目标

### 2.1 比赛目标

初赛提交一套**可信、可演示、低侵入**的材料：

1. 作品信息收集表（Word）；
2. 作品介绍 PPT（Gemini 新版）；
3. 3 分钟 Demo 视频（AgentArts 平台段 + 原项目产品段）；
4. 必要的截图/链接。

不要求交代码包；核心是让评委相信“真的用了 AgentArts”，而不是“套壳聊天机器人”。

### 2.2 技术目标

- 保留原项目（Vue + Spring Boot + FastAPI）不动；
- 用 AgentArts 平台知识库 + 3 节点工作流证明“知识接入 + 编排 + 运行”；
- 用原项目前端证明产品完整度；
- 用版本记录/命中测试证明可复现。

### 2.3 不追求

- 不追求 12 节点全量迁移；
- 不追求 10 个 MCP 工具全部上线；
- 不追求 API 部署（runtime 未激活）；
- 不追求学习效果实验。
