# 01 · 给 Gemini 的 PPT 生成提示词

> 用法：把整个 `ppt-kit` 文件夹（或压缩包）上传给 Gemini，然后把下面 **“复制区”** 的全部内容粘进去。
> 如果 Gemini 能直接生成 PPTX / Google Slides，就让它生成；不能的话，让它按页输出可复制的文案 + 版式 + 图片位置。

---

## 复制区（从下一行开始）

你是资深品牌演示设计师，做过产品发布会、咨询提案和高校竞赛路演。现在请为我重做一份 **16:9、12 页、中文** 的竞赛 PPT。

### 一、先读这些文件

请先完整阅读并遵守：

1. `00-PPT内容脚本.md`：逐页标题、正文、图片、版式建议、口播。
2. `references/facts.md`：唯一允许使用的数字与事实口径。
3. `references/architecture.mmd`：整体架构关系。
4. `screenshots/`：5 张原项目线上实例截图（2026-10-28）。

### 二、这份 PPT 的目标

让评委在 3 分钟内看懂三件事：

1. 这是一个**真实课程学习场景**，不是通用 ChatBot；
2. 它用 **AgentArts 工作流 + 平台知识库 + MCP 工具** 把“画像→证据→生成→门禁→路径”跑成闭环；
3. 它有**可验证的工程与质量数据**，但不过度宣称学习效果。

观众：华为 ICT 大赛初赛评委（技术 + 产品 + 投资背景混合）。
场景：线上材料评审 + 3 分钟视频；PPT 会被快速翻阅，所以**每页只能有一个观点**。

### 三、视觉方向（请严格执行）

**关键词**：编辑型产品案例、暖纸、墨色、留白、细线、真实截图当主角。  
**不要**：紫色 AI 渐变、发光大脑、机器人插画、电路板纹理、玻璃拟态、3D 气球、厚重阴影、满屏卡片、密集 bullet。

**画布**：16:9，13.333 × 7.5 in。  
**边距**：左右 0.55 in，上下 0.45 in；12 栏网格，栏间距 0.18 in。  
**配色**：

- 纸底 `#F7F4EE`
- 墨色 `#15212C`
- 华为红 `#C8102E`（只做强调：页码、细线、关键词）
- 青 `#0F766E`（通过/证据/正向数据）
- 琥珀 `#A86412`（提醒/边界）
- 线 `#E3DCCF`

**字体**：

- 大标题/数字：思源宋体 / Noto Serif SC / 宋体（有编辑感）
- 正文：思源黑体 / Noto Sans SC / 微软雅黑
- 代码：Consolas / JetBrains Mono
- 字号：页标题 28–34pt；正文 12–14pt；图注 9–10pt；页码 8pt

**版式规则**：

- 每页一个主标题 + 最多 3 条正文；单条不超过 25 字。
- 大量留白；用细线、编号、留白分隔，不用重卡片堆叠。
- 产品截图至少占页面 45% 宽度；不要做三张很小的缩略图。
- 截图统一圆角 10–12px、1px 边框 `#E3DCCF`；阴影只允许非常轻。
- 截图只做等比缩放/裁切，不拉伸、不改 UI 文案、不覆盖关键导航。
- 标题左对齐；页码右下；章节编号左上（01/11 这种）。

### 四、逐页要求

严格按 `00-PPT内容脚本.md` 的 12 页结构。重点：

- **封面（第 1 页）**：左侧 45% 文字，右侧 55% `01-home.png` 完整竖版截图；不要裁掉顶部导航。截图放进浅色浏览器框。左侧一条 4px 华为红竖线。**给 2 个封面方案，推荐 1 个。**
- **第 2 页**：三列问题卡，底部一条浅红结论带；不要放截图。
- **第 3 页**：五步闭环 + `03-path.png` 右侧；用细线画出“测验结果回流画像”。
- **第 4 页**：2×2 能力卡 + 一条对比表；不要用产品截图。
- **第 5 页**：4×2 角色卡，编号 01–08；每张只放角色名 + 一句职责。
- **第 6 页**：工作流分两层画；主链路 + 门禁/发布/路径；测验分支用虚线。不要把所有节点塞成一行。
- **第 7 页**：三个数字 + 四步流水线 + `02-resource-task.png` 右侧；底部浅青“弱证据拒答”条。
- **第 8 页**：左侧 2×5 工具网格，右侧深色 JSON-RPC 代码块（6–8 行）。
- **第 9 页**：三张 16:10 等大截图横排（`01-home` / `02-resource-task` / `03-path`），每张下方一行标题 + 一行说明；底部一条深色流程条。**这是全片最重要的产品页，截图必须大、清楚。**
- **第 10 页**：左侧 90.5 / 83% 大数字 + 五维条形；右侧 `05-quality.png`；底部浅琥珀“引用校验”条。不要写 88 分。
- **第 11 页**：三种交付 + 复制路径 + `04-evaluation.png` 右侧；底部红色边界提示“不宣称提分”。
- **第 12 页**：深色收尾，三栏“已完成/待完成/边界”；底部 GitHub 链接；不要用产品截图。

### 五、内容与事实约束

- 只使用 `references/facts.md` 里的数字；没有的数字不写。
- 不写“提升学习成绩/提升 X%”；不写“全学科通用”；不写“AgentArts 已全部跑通/API 已上线”。
- AgentArts 平台截图目前待补：如果需要平台画面，用**浅灰占位卡**明确写“待补：AgentArts 控制台截图”，不要拿产品截图冒充。
- 产品截图只来自 `screenshots/`，不要生成/伪造 UI。
- 保留 `AgentArts`、`MCP`、`RAG`、`EduPath` 等专有名词原样；中文为主，英文只做术语。

### 六、输出要求

**优先**：直接生成可编辑的 16:9 PPTX（或 Google Slides），图片嵌入、文字可编辑、字体有 fallback。  
**如果做不到**，按页输出以下内容，保证我可以直接照做：

1. 页面编号 + 页面目标（一句话）
2. 标题 / 副标题 / 正文（逐字，可直接粘贴）
3. 图片文件名 + 裁切方式 + 放置区域（左/右/全宽，占页面百分比）
4. 版式说明（栏数、对齐、层级、留白）
5. 字号 / 颜色 / 线宽
6. 30–50 字演讲备注

另外请先输出：

- 一页“设计系统”（色板、字体、网格、图片处理规则）；
- 2 个封面方案（推荐 1 个）；
- 一份“图片使用清单”（哪张图放哪页、裁切注意）。

### 七、自检清单（交付前逐条检查）

- [ ] 16:9，12 页，页码正确。
- [ ] 没有紫色渐变/机器人/发光大脑/3D 装饰。
- [ ] 每页一个观点，正文不超过 3 条。
- [ ] 第 1 页截图完整、不裁掉导航；第 9 页三张截图等大、清晰。
- [ ] 第 10 页写 90.5 / 83%，不写 88。
- [ ] 所有数字与 `facts.md` 一致。
- [ ] 没有伪造 AgentArts 平台截图；占位卡明确写“待补”。
- [ ] 没有“提升成绩/全学科通用/API 已上线”等过度宣称。
- [ ] 中文排版无孤字、无溢出、无重叠。
- [ ] 产品截图没有拉伸、没有改 UI 文案。

请开始。先给我设计系统和 2 个封面方案，再继续其余 11 页。

## 二次修改提示（如果第一版还不满意）

> 这一版方向对了，但还不够“编辑感”。请做三件事：  
> 1）把每页正文再删 30%，只留一个观点；  
> 2）把第 9 页三张截图放大到各占 30% 宽，图注压到一行；  
> 3）封面右侧截图改成从顶部导航开始、完整显示，不要裁掉浏览器栏。  
> 其他页保持，不要加装饰元素。输出修改后的第 1、9 页和整体目录即可。
