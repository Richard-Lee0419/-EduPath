# 知径 EduPath · PPT 重做素材包

> 用途：把“内容 + 截图 + 提示词”打包给 Gemini，由它重做 12 页竞赛 PPT。
> 版本：2026-10-28　｜　截图来源：原项目线上实例 https://8.136.194.87/

## 怎么用

1. 把整个文件夹（或 zip）上传给 Gemini。
2. 打开 `01-Gemini提示词.md`，把“复制区”整段粘进去。
3. Gemini 会先给设计系统 + 2 个封面方案，再生成 12 页。
4. 如果它不能直接导出 PPTX，就让它按页输出文案/版式/图片位置，你再用 PowerPoint/WPS 排。

## 关键事实（Gemini 必须遵守）

- 8 个角色、12 个执行节点、10 个 MCP 工具。
- 2 门课、108 篇公开语料、约 1,200+ 切片。
- 线上实例：画像置信度 55%、评估掌握度 67%、质量 90.5/100、门禁通过率 83%。
- 工程验证：82 AI / 56 Java / 29 前端 / 2 E2E；不宣称提分。
- AgentArts 平台截图**待补**：已提交公测申请，尚未完成平台搭建；PPT 里不能用产品截图冒充。

## 设计方向（一句话）

**编辑型产品案例**：暖纸、墨色、华为红细线、大量留白、真实截图当主角；不要紫色 AI 渐变、机器人、发光大脑、3D 装饰。

## 注意

- 截图含演示账号 `demo`，不含手机号/邮箱/密钥；不要添加不存在的个人信息。
- 第 1 页封面、第 9 页 Demo 是三张里最重要的，优先保证截图大、清晰、不裁标题。
- 第 10 页写 **90.5 / 83%**，不要写旧版 88 分。
- 如果 Gemini 生成平台架构图，请按 `references/architecture.mmd` 的关系画，不要自己发明系统边界。
