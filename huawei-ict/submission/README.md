## 2. 需要人工替换的占位符

在 docx 中搜索 `【待填写`，共 8 处：

- 学校全称
- 队伍名称
- 指导老师
- 队员 1 / 2 / 3
- 队长手机号
- 队长邮箱
- 团队合照（图片）

PPT 第 12 页的 GitHub 链接已填；如已部署 Demo，把在线地址补到 PPT 第 9 页与 docx“作品展示”。

## 3. 重新生成

```bash
cd huawei-ict
python scripts/build_submission_docx.py
python scripts/build_ppt.py
```

- docx 依赖 `python-docx`，PPT 依赖 `python-pptx` + `Pillow`。
- 截图来自 `evidence/`；替换截图后重新运行即可。
- 源模板不会被修改。

## 4. 提交前必须做的 5 件事

1. 用 AgentArts 真实端点重跑一次，替换 fixture 截图（当前页面有“未上云”标识）。
2. 录 3.5 分钟视频，链接填到 docx“作品展示”和 PPT。
3. 补团队信息与合照，检查没有占位符。
4. 检查所有数字一致：2 门课 / 108 篇 / 8 角色 / 12 节点 / 10 工具 / 9 步 / 88 分。
5. 导出 PDF 备份（Word 排版可能因机器字体变化）。
