## 2. 已填写内容（可直接核对）

### 赛题

> 赛题2：基于华为云AgentArts智能体开发平台的Agent设计和应用

### 作品名称

> 知径 EduPath——基于华为云 AgentArts 的课程学习多智能体

### 应用领域

> 行业赋能型（教育）+ 创新探索型（多 Agent 协同 / MCP 工具调用）。
> 面向高校《数据结构与算法》《计算机组成原理》等专业基础课，解决大班教学中“统一进度无法匹配个体薄弱点、通用 AI 内容缺少课程依据、练习结果不回流学习决策”的问题。服务对象包括学生、任课教师与课程团队；方案可复制到其他高校课程与职业教育场景。

### 应用技术

> 1. 平台与角色：以华为云 AgentArts 为智能体构建、编排、知识与发布平台，创建“知径学伴”主智能体，以及画像、检索、教学设计、资源生成、辅导、评估、安全 7 个角色智能体。
> 2. 工作流编排：意图识别 → 课程/知识点确认 → 画像与检索并行 → 资源规划 → 讲义/导图/题库并行生成 → 质量门禁 → 安全审核 → 发布/落库 → 路径规划；测验分支进入“评估→路径重规划”。
> 3. 知识接入：课程语料经清洗、结构分段（标题层级 3、约 500 字）和元数据标注后接入 AgentArts 平台知识库，使用 pangu_embedding + pangu_rerank；生成内容强制引用 chunk，弱证据拒答。
> 4. 工具编排：通过自定义 MCP 服务把 EduPath 既有课程、画像、题库、路径能力注册为 10 个工具，实现低侵入复用，原项目代码零改动。
> 5. 模型与发布：使用 MaaS 的 DeepSeek-V4-Flash / 盘古模型与 Token Plan 代金券；通过 AgentArts 发布 API/Web，前端以 SSE 展示 Agent 协作轨迹、证据与产物。

### 作品介绍（369 字，≤500 字）

> 高校专业基础课普遍面临“大班统一进度”与“个体差异”的矛盾：学生不清楚自己弱在哪，教师难以为每人生成练习，通用 AI 又常给出脱离教材、无法核验的内容。知径 EduPath 以华为云 AgentArts 为底座，把学习画像、课程证据、资源生成、路径规划、智能辅导与测验评估串成可执行闭环。
> 画像 Agent 从学生自述中提取目标、薄弱点、偏好与时间预算；检索 Agent 在课程知识库中取证；教学设计与生成 Agent 依据证据产出讲义、思维导图、题库和代码实验；评估与安全 Agent 分别做质量门禁和内容审核；测验结果再回流画像与路径，形成持续调整。所有生成内容标注来源，Agent 协作过程可视化、可追溯。
> 项目已完成两门课程、108 篇公开语料与完整工程验证，可低侵入接入 AgentArts，并复制到其他高校课程与职业教育场景。
