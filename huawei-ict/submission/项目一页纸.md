# 知径 EduPath · 一页纸

> 基于华为云 AgentArts 的课程学习多智能体　｜　第十一届华为 ICT 大赛 · 赛题 2

## 问题

高校专业基础课“一个班一套进度”，学生不知道弱在哪、下一步学什么；通用 AI 内容脱离教材、无法核验；练完没有反馈。

## 方案

一条可执行闭环：

```text
画像 → 课程证据 → 资源规划 → 讲义/导图/题库 → 质量+安全门禁 → 学习路径
                                                    ↑                 │
                                                    └── 测验结果回流 ──┘
```

- 8 个角色：主控、画像、检索、教学设计、生成、辅导、评估、安全。
- 12 节点工作流：并行检索/生成、双门禁、发布、测验重规划。
- 10 个 MCP 工具：既有能力低侵入复用，原项目 0 行修改。
- 平台知识库：2 门课、108 篇公开语料、约 1,200+ 切片，保留来源/许可证。
- 每条结论带 `[E#]`，可点回 chunk；弱证据拒答。

## 差异

| 对比 | 通用助手 | 题库 | 我们 |
| --- | --- | --- | --- |
| 内容依据 | 通用知识 | 题目解析 | 课程 chunk + 来源 |
| 个性化 | 对话上下文 | 错题标签 | 版本化画像 + 测验回流 |
| 过程 | 黑盒 | 无 | Agent 轨迹 + 工具 + 证据 |
| 发布 | 无门禁 | 无 | 质量 + 安全双门禁 |

## 证据（如实）

- Demo：9 步轨迹、5 条证据、3 类资源、质量 88/100、安全 4 项通过、3 天路径。
- 工程：AI 82 项、Java 56 项、前端 29 项断言、2 项 E2E；真实 HTTP 五任务闭环。
- 边界：2 门课；无学习效果对照实验，不宣称提分；fixture 截图已标注“未上云”。

## 落地

- 交付：课程包 / 教师工作台 / SaaS。
- 复制：换语料 → 标知识点 → 配评测集 → 跑工作流。
- 目标：教师备课 45→15 分钟；任务成功率 ≥95%；引用可追溯 100%。
