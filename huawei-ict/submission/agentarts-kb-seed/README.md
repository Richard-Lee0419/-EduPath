## 上传步骤

1. AgentArts 控制台 → 左侧 **开发中心 > 组件库** → **知识库** 页签。
2. 右上角 **创建知识库** → 选择 **默认** → 确定。
3. 填写：
   - 名称：`edupath-course-kb`
   - 描述：高校数据结构课程证据库（二叉树遍历/基础/DFS/BST）
   - 向量模型：`pangu_embedding`
   - 精排模型：`pangu_rerank`
   - 解析配置：不配置
   - 拆分设置：自动分段
4. 创建后点知识库名称 → **上传文档** → 选这 4 个 `.md`。
5. 等文档状态变成 **成功**。
6. 右上角 **命中测试**，依次输入下面 4 条。
