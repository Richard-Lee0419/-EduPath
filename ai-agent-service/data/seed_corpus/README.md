# Seed corpus

This directory contains the public seed corpus loaded by the AI service at startup, plus source and license manifests. Consult open_source_manifest.json and the root docs/open-source-knowledge-base.md before redistributing or replacing any source.

To build a corpus from authorized local course materials, see ../course_corpus/README.md. The bundled seed is useful for development and functional testing; it does not by itself prove complete coverage of a new course.
