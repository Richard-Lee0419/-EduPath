# 二叉树递归遍历与错因诊断

EDUPATH-TREE-DFS-V1 · 《算法与数据结构》· EduPath 团队自编 · v1

## 三种遍历中的访问时机

EDUPATH-TREE-DFS-V1:order
空子树立即返回。每个非空节点递归处理左、右子树各一次。前序在两次递归之前访问根节点（根→左→右）；中序在两次递归之间访问（左→根→右）；后序在两次递归之后访问（左→右→根）。到达节点的时刻和把节点写入输出的时刻可以不同。

## 固定左右子树顺序

EDUPATH-TREE-DFS-V1:direction
在前序、中序和后序的通常定义中，先完整处理当前节点的左子树，再处理其右子树。左或右孩子为空时跳过。左右孩子的位置随题目给定，不随节点字母大小变化。父节点 A 的左孩子 B 和右孩子 C 不可互换。

## 检查节点是否恰好输出一次

EDUPATH-TREE-DFS-V1:coverage
在一次完整的递归遍历中，每个非空节点应恰好出现在输出序列中一次。空指针不输出节点。核对时可先比较序列里的节点集合及次数，再逐步核对访问顺序。

## 前序示例

根 A 的左右孩子是 B 和 C，B 的右孩子是 D。进入 A 时先输出 A，再递归到 B 与 D。在 B 的子树处理完成并返回 A 后，才处理 C。该二叉树前序为 A→B→D→C，中序为 B→D→A→C，后序为 D→B→C→A。
