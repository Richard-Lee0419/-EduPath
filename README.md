# -EduPath
知径 EduPath 是面向高校专业课程学习者的 AI Native 个性化学习平台，聚焦学习起点难判断、资源难匹配、路径难安排、练习结果难以回流等真实断点，构建“画像—证据—资源—路径—评估”学习闭环。系统通过多智能体协作完成画像理解、课程知识检索、六类资源生成、路径规划、智能辅导、测验评估与补救复测；以可修正、可追溯的动态画像连接学习需求与行为，以 RAG 课程证据和 SafetyAgent 约束内容质量，并展示推荐理由、证据来源和任务进度。平台已完成云端部署，在《数据结构与算法》《计算机组成原理》上完成同构验证，同时提供教师端班级洞察与教学支持，形成面向学生学习与教师决策的可运行系统。
